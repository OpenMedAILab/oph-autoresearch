# 研究项目与服务器工作目录绑定

新建研究项目必须选择已保存的 SSH 服务器及服务器工作目录。本机目录可以选择已有文件夹，或按项目名自动创建；服务器目录必须已存在、在该 SSH 配置允许根目录内且可写。创建前通过 SSH 校验规范化路径与目录权限。

项目账本持久化 `serverBinding`（迁移 39）：连接标识、规范化服务器目录、连接配置摘要及验证时间，不复制密码或私钥。项目、绑定与首会话在同一个事务内保存。旧项目仍能打开，可从项目侧栏首次补绑；已有绑定不能静默改派到不同服务器、目录或连接身份。连接配置被删除或变更后，执行端必须明确报错。

`scopeSshProfile` 将文件工具的允许根目录缩小到绑定目录；SSH 命令默认在这个目录启动。主控 CLI 上下文仅包含绑定服务器的远程 CLI 能力，以及本机/服务器目录关系。API 主控由运行时注入可信 `ToolContext.projectServerBinding`。这不是文件同步服务，也不把普通 SSH shell 宣称为操作系统隔离环境；正式实验仍需独立的冻结计划与执行准入。

Web 支持首项目创建前配置 SSH、浏览服务器子目录、新建后显示服务器目录、旧项目补绑。进入 SSH 配置时关闭创建遮挡，重新打开保留项目名和本机目录草稿，并要求重新选择服务器。SSH 页面提供“打开绑定目录”，从服务端重新解析项目绑定再连接；切换项目时清除旧连接视图，迟到的连接结果不能覆盖新项目。
