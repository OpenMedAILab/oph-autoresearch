## 不变量与证据

- client dispatch key → Attempt ID → remote job key → frozen spec hash，身份不能混用。
- 执行租约、客户端观察连接、最大运行时间分别管理；心跳不能无限扩预算。
- `unknown` 不自动重投；取消请求不等于进程已停止。
- CLI 负责准备代码的产物也要先冻结，改变代码/数据/统计方案后需要新修订与批准。
- 进程完成、产物完整、独立复核和人类发布是不同状态；负结果不是执行失败。
- 本地合成数据真实训练不等于真实 SSH/GPU/外部 AI CLI 已验收；尚未运行的能力必须明示。
- API、本机原生 CLI 和 Web 共享研究控制语义，远程 CLI 仅作为 worker 能力展示。
- 准备任务的费用未知会保留预留，与模型复核预留合并计算；不得仅有 CLI 预留时改变币种。预留不是 CLI 服务商实际费用硬上限。
- CLI 准备的运行时限由 authority 执行；1 CPU / 256 MB 是计划资源，当前不是操作系统强制限制。禁 CLI 工具与最小环境不能替代宿主读取隔离。

基线研究测试 140 通过、1 失败（macOS 测试错误调用 Windows `cmd`）。全量基线 2385 通过、1 跳过、7 失败；失败明细见本地 `.tmp/pro-implementation/baseline-full-tests.log`，不提交运行日志或凭据。

## Web 开发入口与接下来的依赖

准备能力由管理员配置，SSH 登录探测不会自动配置执行能力。本机 `oph serve --research-cli-preparations <file>` 读取已准入路由数组，路由绑定设备、模型、适配器身份哈希以及 `SshDaemonConfig`；远端 `oph research-daemon --config <file>` 中的 `cliPreparation` 固定工作范围、凭据目录、真实二进制和适配器身份。敏感配置放在仓库外，不把 token/私钥写入研究文档。Web 的“远端 CLI 代码准备”只列已配置路由，独立审批仍走现有签署器。

下一批先完成候选代码的单独正式执行契约与实际隔离验证：冻结入口、依赖环境、输入快照和输出规范，批准每任务 runtime 与可执行的资源限制，验证进程、网络和文件边界，再做绑定批准的真实 SSH/CLI 与严格超过 10 分钟耐久验收。随后推进 P1 自动迭代/全文证据整理/稿件图表与实际通知适配器；P2 行为评测、人工晋级和多设备调度依赖上述真实记录，不自动开放。
