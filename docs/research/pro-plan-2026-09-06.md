## 不变量与证据

- client dispatch key → Attempt ID → remote job key → frozen spec hash，身份不能混用。
- 执行租约、客户端观察连接、最大运行时间分别管理；心跳不能无限扩预算。
- `unknown` 不自动重投；取消请求不等于进程已停止。
- CLI 负责准备代码的产物也要先冻结，改变代码/数据/统计方案后需要新修订与批准。
- 进程完成、产物完整、独立复核和人类发布是不同状态；负结果不是执行失败。
- 本地合成数据真实训练不等于真实 SSH/GPU/外部 AI CLI 已验收；尚未运行的能力必须明示。
- API、本机原生 CLI 和 Web 共享研究控制语义，远程 CLI 仅作为 worker 能力展示。

基线研究测试 140 通过、1 失败（macOS 测试错误调用 Windows `cmd`）。全量基线 2385 通过、1 跳过、7 失败；失败明细见本地 `.tmp/pro-implementation/baseline-full-tests.log`，不提交运行日志或凭据。
