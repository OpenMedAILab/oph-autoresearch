# 任务修订、证据绑定和本地受控协议

2026-09-05。本批在原 ResearchEvent 唯一账本上增加合同字段，不新建状态库，不修改旧迁移。历史快照缺少新增字段时仍可读取和重放。

`declareSyntheticTask` 声明固定合成任务的逻辑 taskId、修订号、前一修订、确切 artifactVersionIds 和策略/输入/预算上下文哈希。执行的技能标识、版本、来源内容哈希、评估合同哈希和模板标识进入 TaskRevision，并纳入批准 bundle。Runner 领取时核对该绑定，不允许用相同 dispatchKey 偷换输入或任务规格。HTTP 声明入口只绑定代码内固定技能，候选来源不因此获得执行权。

新的上游产物版本只使实际消费旧版本的任务失效，并经明确 producerTaskRevisionId/producerAttemptId 边传递到下游。修订不会改写旧规格或删除旧 Attempt、产物、负结果。已有运行若期间依赖变化，不得提交有效完成结果。未受影响分支保留原状态。改变全局策略、输入或预算则使绑定旧上下文的任务失效。此处 artifact 依赖是证据/协议引用；执行数据仍只有固定合成 fixture，不代表可运行任意用户数据。

机器复核模块只接收真实文件字节，不接收聊天、执行者 verified 声明或执行者计算出的 expected 结果。它从固定原始 fixture 独立重算，拒绝额外字段、错误版本、非有限统计、超大内容、错均值和不完整 JSON。生产 Attempt 和不可变产物版本显式关联，完成记录保留核验哈希、长度与时间。该过程是机器复核，人工批准通道仍关闭。

`local-synthetic-v1` 的 submit/status/cancel/receipt 共用原执行和账本。status 只观察，不自动重派；cancel 请求与执行终态分别报告；相同 dispatchKey 丢失响应后重放不执行第二次。receipt 只接受明确完成的生产 Attempt，重新读取派生固定路径的字节、核对产物绑定和 hash、重算统计并拒绝已失效任务。HTTP 提供相同 status/receipt 读取接口。

这不是远端 SSH 守护协议；远端失联、租约 fencing、通用资源调度和临床执行仍未实现。当前故障注入仅证明本地丢失确认、取消确认、未知尝试、内容篡改和版本变更的行为。实际临床服务器未访问。

Skill 来源区分 local-bundle 与 git-pinned。基线 commit 不证明本地新增 fixture 已在该提交中。可复用锁读取端口每次比较固定来源快照及字节，真实 read_skill 和合成研究装配消费同一端口；研究端口没有命中时不回退到工作区技能。普通会话行为保留。未准入外部候选仅核验保存字节，既不安装也不执行。这个内容锁不构成任意工具、脚本或操作系统网络隔离。
