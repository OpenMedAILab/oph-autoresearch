## 当前唯一权威与原地改点

ResearchEvent 是科研事实唯一真源，继续使用其原子投影和幂等写入路径。新增 TaskRevision 是固定模板与输入/输出合同的不可变声明；Attempt 记录一次真实执行，状态与验证结果由科研事件落库。不存在另一个可以独立作数的 Runner 状态数据库。进程 Map 仅持有取消句柄。

原始风险在执行边界：如果先写文件再记录 Attempt，崩溃后无法判断是否发生执行；如果收到相同请求就再次调用模板，会创建重复产物。本批先事务 claim，再执行一次；重复 dispatch 只读回既有结果，中断不自动重跑。

## 执行边界

只开放固定 `synthetic-summary-v1`，数据只来自随代码打包的合成 fixture；不接受用户命令、路径、模型、SSH 主机或真实数据输入。该模板仅是无需人工批准的本地合成 smoke，不代表临床通道已治理，也不授予任何真实科研操作能力。

Runner 将产物写到按 Campaign/Attempt 派生的独立目录，拒绝路径逃逸和软链边界，不删除失败目录。写完重新读取字节计算 SHA256，并核验合同、有限数值、数量和输入版本后才记录验证通过。exit code 或“成功”文本不是验证证据。

取消先记请求再终止协作阶段；失败/取消/进程中断保留 Attempt。重启仅回收无人持有的执行，不把另一存活服务进程的工作误标中断。PID 存活仅是保守的本地持有提示，不能作为跨主机身份。

## 传输与界面

Outbox 与事件同事务写入，发布后标记 delivered。发布和提交之间崩溃可能重投，客户端按 campaignSeq 去重；全局 EventBus seq 只负责传输流。通知仅带标识与序号，界面重新读取持久化快照；缺口和重连以 REST 补齐。

界面创建/执行期间切换会话，旧操作的反馈不能写入新会话。旧聊天视图继续显式未核验。

## 路径增减与复审

新增的是用户授权的固定合成本地执行入口，状态持久化仍只有原 ResearchEvent 路径；不新增第二套通用 Agent 框架。没有将关闭的人类批准端点改为 nonce 冒充身份。也没有因真实 SSH 未提供而停下可在本地完成的执行、恢复、canary 与供应链工作。

本批尚不覆盖完整 Pro P0：全平台数据出口策略、真实人类审批、SSH Runner、图依赖闭包、自适应团队和技能供应链继续列为后续工作。
